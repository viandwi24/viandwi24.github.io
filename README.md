# viandwi24.com

Personal website of Alfian Dwi Nugraha, built as a cozy isometric voxel world you can walk around.

![Living room](docs/screenshots/living-room.webp)

Made with Svelte 5, Three.js and TypeScript, in a pixel-art voxel style.

## Run locally

```sh
bun install
bun run dev
bun run build
```
